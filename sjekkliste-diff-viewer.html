FASIT

Slik skal en regel skrives

En regel har alltid formen If (betingelse) then (utfall). Det finnes to gyldige regeltyper, og det er utfallet som skiller dem:

1

Peker på sjekkpunkt

Når betingelsen er oppfylt, blir sjekkpunktet aktuelt og skal vurderes. Utfallet er bare sjekkpunktets Id.

If ( 1.73 = truebetingelse ) then ( 1.28sjekkpunktet som skal vurderes )

Leses: «Hvis 1.73 er ja, skal 1.28 vurderes.»

2

Preutfylling

Når betingelsen er oppfylt, kan sjekkpunktet besvart med verdien i utfallet. Brukes normalt på sjekkpunkter av typen Auto.

If ( norskSvenskDansk = truebetingelse, ofte et datafelt ) then ( 1.1 = truesjekkpunktet og svaret det får )

Leses: «Hvis norskSvenskDansk er ja, besvares 1.1 med ja.»

Skrivemåte – gjelder begge typene

Krav✓ Fasit✗ Finnes i dag
Ingen linjeskift eller mellomrom før/etter If (1.73 = true) then (1.28) If (1.73 = true) then (1.28)↵
Ett mellomrom rundt =, & og || If (3.55 = true) then (3.57) If (3.55= true) then (3.57)
Hele betingelsen i én parentes If (8.8 = false & 8.10 = false) then (8.12) If (8.8 = false) & (8.10 = false) then (8.12)
Hvert ledd har egen = true/= false If (1.26 = true || 1.27 = true) then (1.25 = true) If (1.26 || 1.27 = true) then (1.25 = true)
Blandes & og ||: parentes rundt gruppen If (2.12 = false & (3.13 = true || 3.20 = true)) then (2.9) If (1.20 & 1.21 || 1.22 = true) then 1.108
Datafelt i camelCase If (tegningNyPlan = true) then (1.79 = true) If (TegningNyPlan = true) then (1.79 = true)
Én regel per felt – ikke begge typene i samme felt If (1.74 = true) then (1.76) og, i 1.42: If (1.76 = true) then (1.42 = true) If (1.74 = true) then (1.76) & (1.76 = true) then (1.42 = true)
Utfallet er ett sjekkpunkt-Id If (3.1 = true) then (3.2) If (3.47 = true) then (RKO), Vedlagt underskjema

Det finnes ingen vedtatt standard for Regel-feltet. Fasiten er tolket fra skrivemåten flest regler allerede bruker.

Vurderinger og alle avvikstyper 
Regel         = "If (" Betingelse ") then (" Utfall ")"
Utfall        = Sjekkpunkt-Id                        peker på sjekkpunkt: skal vurderes
              | Sjekkpunkt-Id " = " ("true" | "false")   preutfylling: besvares automatisk
Betingelse    = Ledd { (" & " | " || ") Ledd }      – blandes & og ||: parentes rundt gruppene
Ledd          = (Sjekkpunkt-Id | datafelt) " = " ("true" | "false")
Sjekkpunkt-Id = tall "." tall                        f.eks. 1.28
datafelt      = camelCase                            f.eks. norskSvenskDansk

Følger fasit – regelen er skrevet nøyaktig slik. Kan rettes automatisk – regelen er entydig, og verktøyet viser hvordan den skal stå. Må vurderes manuelt – fritekst, flere regler i ett felt eller uklar logikk som et menneske må ta stilling til. Kryssjekk – regelen er lesbar, men stemmer ikke med resten av sjekklisten.
